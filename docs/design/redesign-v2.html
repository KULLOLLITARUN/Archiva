What are the steps to clone the Azure VM?
ExplainSelf-healed

The plan uses the Snapshot → Managed Disk → Specialized VM method, so the original VM is never modified.

  1. Safety snapshot of the Win11-Recovered OS disk.
  2. Clone 1 — snapshot, managed disk, then create Dev-Clone-1.
  3. Clone 2 — repeat with its own names.
  4. Verify each clone's public IP and RDP on port 3389.

Never use Sysprep or a generalized image — that is what broke the previous attempt.
